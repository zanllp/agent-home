# 窗户、墙面与屏幕细节

## 窗户分层

`house3d/web/window-detail.js` 在已有落地窗实例的位置/朝向上生成独立的 Three.js 网格：

- 室内层：窗洞内衬、外框、两扇错层推拉框、密封条、三道轨道、把手和螺钉、窗台。
- 织物层：有真实起伏的褶皱窗帘、纱帘、下摆和吊环；不是平面窗帘图片。
- 阳台层：现已拆为可走入、可编辑的独立区域，结构见 `balcony.js`，摆件由常规物品状态加载。远景图片由阳台外窗/室内门洞遮罩限制，不盖住真实家具。

窗户不再内嵌洗衣机、绿植或毛巾。门的三扇网格随 `open` 状态叠放/关闭；只有真实开口可通行。详细工具用法与边界见 [阳台说明](BALCONY.md)。人物及原 GLB 保持不变。

## 屏幕与墙面

电视先显示原来的「周末片单」频道首页（本地庭院插画与节目卡片），停留 6 秒后播放三段本地原创卡通（单车、帆船、气球），随机轮播，每轮不重复；三段播完再回首页。双屏独立轮换编辑器/终端和随手记/周计划。它们不是实际桌面，不依赖网络视频或声轨；只在房间可见且未暂停时按低帧率刷新。

墙面增加轻微灰泥起伏、木饰条和插座。墙纸仍由原工具控制；窗口与饰面区域重叠时隐藏该块饰面，避免堵住真实窗洞。

## 验证

`house3d/test_visual_detail.mjs` 覆盖门扇叠放/关闭、实例隔离、共享纹理清理、显示屏局部坐标与移动窗洞。浏览器人工检查全景及斜侧近景。图像并不承诺参考图级别的完整室内光线追踪；当前仍是浏览器实时光照。

## 室内光影与家具

有真实窗洞时，天花板只投影、不遮挡俯视镜头；窗框投影而玻璃不投实心阴影。日光、窗边补光和家具表面反射跟随窗户方向，日间、傍晚和夜间使用不同强度。地板接触阴影在布置更新时重算，不随角色每一帧重算；它不是地毯或桌面上的环境遮蔽。

宽阳台门的午后阳光从侧面斜照到地毯，保留窗框、沙发和盆栽投下的阴影。小窗仍沿用原入射角，傍晚和夜间不套用日间的暖色强度。

沿用原家具彩色贴图。带独立材质的模型保留原有分材质；旧模型按材质名或家具主体区分布艺、木材、涂层、金属、纸张和叶片。单张贴图合并了多个部件的模型不会因此被自动拆分。人物继续使用无光照材质。

## 玩玩具时的近景

地面坐姿不沿用椅子坐姿的腿部校形。玩玩具时，双膝向外、小腿一前一后交叉，脚上只留短袜。袜尖、脚踝与膝面是同一层连续几何，各自跟随同侧骨链；走路和坐椅子时仍显示原鞋。前襟与腋下补面跟随躯干而不是头部，领结和胸针绘在独立的弧形衣片上。退出这个动作会恢复原几何和材质，不修改角色 GLB。

## 家庭墙面

家庭预设的工作区有装裱的野餐画、可调亮度的小台灯和出门小挂钩，电视墙上是跟随浏览器本地时间的榉木钟。这些摆件可用 `update_layout` 单独移动、换墙或移除；扫地机只是可摆放的模型，不会自行清扫。都市素墙的细拼缝按实际窗洞分段；换上墙纸不会继续叠在墙纸上。

房间全景按两面墙、地板和阳台外缘构图，窄屏也保留房间边角和底部按钮空间；它与室内直播机位独立。画画的正面、侧面镜头会比较两侧家具的位置，尽量让脸和纸避开书柜遮挡。这是根据家具尺寸选择机位，不是逐三角形的可见性保证。

沙发软装使用同一块实测座面：靠枕放在原有背垫前面，鲸鱼的腹部略压平，流苏毯顺着扶手外缘下垂。三件都是独立摆件。布置变化时，摆件向实际坐垫网格投一次局部接触阴影；没有在座位上叠一张平面，也不需要每帧重算。家庭阳台的晾衣架仍可独立移动；架上的短袖和两条棉巾是装饰，不是单独可拿取的衣服。窗帘有织纹和稍微散开的下摆，内层纱帘不投实心阴影。

家庭书墙是靠墙的枫木柜，下部为奶油色底柜，上部有五个真正承托物件的开放层板。绿萝层板移到窗边挂钩上方。自然书、睡前故事、技术书和三种带纸签的布盒可从目录分别选择；每组书共用一张书脊印刷图。夹在两侧封面间的浅色纸页在近景可见。柜门是装饰，不代表有开门动作。

家庭版机器人玩具不带厚坐垫。盘腿时降低骨盆并让小腿展开，脚底贴近地毯，接触阴影按当前骨骼位置绘制。尾鳍只在坐稳时用原网格和原贴图贴近身侧，起身恢复原模型。旧带垫玩具和其他动作保持原状。装配册和零件盒属于同一玩具套件；收拾会把机器人与七件散件放回盒中，不会清除纸页。

电视墙是独立的「港湾灰蓝」哑光面，使用已有的 `set_wallpaper` 即可更换；颜色和微小的墙面凹凸都不会叠到下一款墙纸上。白橡木矮柜的顶面、上格和下格分别受光。书册或掌机换层时，其接触阴影跟着物件换层；柜门和遮线布面为装饰。

家庭客厅用一张约 3.74 × 2.48 米的拼织毯把沙发、矮茶几和拼装区连在一起。地毯使用本地织纹图，不包含家具或阴影。地板和毯面共用布置变更时采集的软阴影：桌脚下窄、桌板和沙发下宽；角色盘腿时仍使用随骨骼变化的接触阴影。茶几可独立移动，台面上的周末茶点组合随它移动。

家庭预设里，儿童桌上方的枫木作品板挂着机器人图、花园观察卡和周六手作票；这些是随模型提供的印刷品，不是角色正在画的那一张。玄关的帽袋架是独立墙饰，鞋柜、柜上画框钥匙碟、换鞋区和拖鞋也都可通过 `update_layout` 调整。移动换鞋区时，两双拖鞋会跟随自己的支撑面。门仍是装饰门。

宽阳台的日光沿窗洞投进屋内。木地板用低光泽清漆；间接暖光的中心按窗户位置和太阳入射方向计算，模拟地面反射，不是全屏暖色滤镜。书桌和玄关柜上的摆件也在真实支撑面上留下接触阴影；书包挂钩不算桌面。改动都在浏览器侧，不需要服务器渲染。

**全屋留影**采用更长的镜头，把室内两面墙、家具和地板前缘一起收进画面，不预留操作栏的位置。它是干净的剖面全景；「家庭直播」则仍是房间里能拍到天花板的摄像头。点标题旁的「留影」或按 G 进入；点画面或按 Esc 回全景。不会自动摆人物姿势。Agent 可以先 `set_camera {"preset":"album"}` 再拍普通截图。

家庭书桌墙把蓝灰色留给成人工作位，儿童作品板挂在浅色墙面上。木搁板放盆栽，布罩小灯落在工作桌；儿童阅读灯的局部光照向桌面，单独关灯不会调暗全屋。
儿童作品板展示屋内绘本上最近的一张蜡笔画，题名照原画保留；没有画时显示机器人卡片，不改原画也不占新的家具位置。

电视墙上的空调保留原有安装尺寸和挂高，近看可分辨面盖、导风片、上方回风格栅和红外接收窗；它仍是静态家具，不报告温度或制冷状态。空调、时钟、画框、作品板和搁板的贴墙暗部随摆放更新，窗洞处留空；这层暗部只表现环境遮蔽，不代替日照投影。

窗边的灰蓝布帘和米白窗纱分别挂在前后两条轨道上。下摆比帘头更宽，窗纱折边透光弱些，中间仍能透见远景。两层帘子都收到门侧，不拦阳台通道，也不改变门扇状态。

家庭地毯的拼装组有两台不同的机器人：大肥鱼拿着圆头机器人，带翼的小巡游号站在脚边。收玩具时，两台在盒子前格并排站好，七块零件进后格；装配册留在地毯上。人物外形、玩具组占地和 Agent 的 play、tidy、unpack 指令均未改变。地毯沿用原始织纹，降低大块色差，在边沿织一圈小菱纹。玩耍时的正面和斜侧机位同时考虑脸、双手和地上的玩具；全屋留影则保留完整房间轮廓。

宽沙发保留原坐垫的缝线和深色木脚，面料调为燕麦色。坐面上的蓝灰毯跨过真实扶手后自然下垂，内侧折角、包边和流苏从侧机位也能看到；沙发、毯子、靠枕和鲸鱼仍是可单独换下的物件。

家庭房的橡木地板沿用原木纹图，每块板单独取纹并错缝铺设。板边有浅倒角，每块漆面的光泽略有不同；整片地板只画一个网格，改变房间尺寸时才重排。经典儿童房保留原地板。宽窗的午后日光能斜穿地毯到达餐区，椅脚附近的窄阴影与桌面下方的柔和暗部来自家具本身，移动桌椅后会随布置更新。

**入户处。** 橡木门内侧保留了几年的铅笔身高线；门套、猫眼、内把手和门槛是实体细节。乳白面板随门显示在锁舌侧，有其他墙件或遇到墙角时省略。它不是灯光指令，门也不是新的通道。深色编织垫嵌在可移动的玄关地台里；两双拖鞋保持独立，不占新的布置名额。
