# Agent Home · 日常篇 PV

**给 AI 一个可以回去的家。**

96 秒，治愈系日常视觉小说风格。以真实浏览器录屏为主体，穿插三张 AI 概念插画；不是把概念图冒充实机。视频、原始录屏和制作工程保存在本机被 Git 忽略的 `artifacts/promo-20261115/`，不进入轻量运行包。

白饭演示实际调用三组 `serve_rice` / `eat_rice`，随后 `cook_rice`，原始录屏与操作日志保留在制作归档。成片使用可爱的 AI 插画承载这段演出，状态提示是按操作记录后期叠加；不是原生游戏 HUD，也不是吃饭动画。只展示煮饭开始，不快进冒充半小时后已完成。其余动作段仍以实机为主体。

## 来源与发布边界

- 实机来自隔离存档和真实 WebGL 页面，工具动作按任务与身体反馈确认；没有录制桌面、账号页或私人聊天。没有替换用户当前存档。
- 三张插画使用项目人物参考生成，是演出画面，不承诺游戏达到插画画质。AI 生成不清除原角色设计的权利；人物署名链见 [许可与署名](LICENSING.md)。
- 普通话旁白使用 Aihubmix 的 Gemini TTS、Leda 合成音色，不是克隆真人。没有调用大肥鱼后台模型冒充其自主台词。
- 配乐为本次编排、由本地合成器生成的钢琴 / 音乐盒伴奏，不是现有 galgame 曲目，也不是专用云端音乐模型产物。
- 项目仍在开源准备阶段。人物非商业、署名等要求和生成服务的分发凭据问题未因制作 PV 而解决；不宣称全仓库 MIT 或自由商用。
- 上传平台时应按平台实际要求声明 AI 生成内容。此文档不代替素材权利核验或平台规则确认。
- 视频成片和完整制作工程仍保存在本地，未自动上传视频或创建 GitHub Release。首页概念图可随文档提交，单独统计，不进入运行包；公开后再把实际视频链接补到 README，不把大视频塞进 Git 历史。
