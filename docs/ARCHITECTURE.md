# 架构与运行边界

## 一次构建、Node 服务与浏览器执行者

TS 后端 → esbuild → `runtime/server.mjs`；浏览器源码 → Vite → `runtime/web/`。构建仅由开发/发布者执行。运行者使用 `node start.mjs`，不用安装 npm 包、Python 或原生数据库模块。后端只导入 Node 内置模块；第三方前端 Three.js 已包含在浏览器 bundle。

要求 Node 22.12+。22.12 的 SQLite 开关由启动器用同一个 Node 可执行文件自动处理；无需执行 shell、下载安装或改变全局配置。新版本无需额外开关。实验性 SQLite 提示来自 Node，未通过屏蔽警告冒充 API 已稳定。

## 状态链路

1. Agent 通过 Node CLI 或本地 HTTP 调用声明工具。
2. 后端检查参数、版本、幂等、布置和支撑关系，在 SQLite 事务中落盘。
3. 默认 headless Runner（关闭时为可见生活页）轮询期望状态，执行导航/姿态，再回传身体快照和动作进度。
4. Agent 用 `observe_home` 检查匹配 job、fresh、完成/受阻，不能把命令受理当完成。
5. 截图由执行者渲染后上传到本地队列，Agent 取得 PNG。不是桌面、摄像头或其他应用截图。

## 代码

- `house3d/server/app.ts`：保持原 HTTP 路由与命令响应。
- `transition.ts`：状态转换、房间/物品操作。
- `geometry.ts` / `layout.ts`：尺寸、支撑、碰撞与近似可达性。
- `objects.ts` / `observation.ts`：动作声明、角色视角与反馈。
- `store.ts`：内置 SQLite、事务、幂等记录、事件与执行者租约。
- `index.ts` / `cli.ts`：HTTP 服务与命令行入口。
- `house3d/shared/space.mjs`：室内/阳台区域、门口与护栏边界，服务端与画布共用。
- `house3d/web/`：原浏览器生活画布；当前 GLB 和纹理保持不变。
- `tests/`：旧 HTTP 契约重放、原 SQLite 兼容、真实 HTTP 和无依赖运行包验收。

## 存档

默认数据库仍是 `house3d/data/house.sqlite`，保留 state/commands/shots/home_events/home_viewer 表。已有 state 不重置，旧 Python 格式的幂等请求可以重试；旧 shots 表缺 view 时只补原有同一列。没有改为 JSON 文件存储或新业务兜底。

运行包不携带数据库。更新/恢复前正常停止旧实例，保留并备份自己的数据；不要运行中替换数据库，也不删租约来抢身体执行权。

## 安全及限制

只监听 127.0.0.1。保留本机 Host、跨源写入、5 MiB 请求体限制和静态目录边界；不开放公网/认证权限，不接 DSH/QQ/模型服务。参数只影响声明的家居状态，不作为 shell 脚本执行。

几何与视野仍基于保守边界/声明支撑面，不是物理碰撞或感知传感器。默认 Runner 推进身体并提供按需截图；它离线后旁观页不会自行接管。见 [Runner 与性能日志](RUNNER.md)。人物仍使用无光照贴图，家具独立受光；无通用换装、多人和内容包市场。

## 空闲渲染

身体执行与画面绘制分开。走跑、起身/坐下、画画、玩玩具及自主逛逛继续按原节奏更新；手动休息或稳定坐卧/阅读后，保留最后的姿态，停止重复骨骼更新和细微待机摇摆。镜头、布置、灯光、操作提示或新指令变化会触发重画，身体反馈轮询不停止。

电视/显示器仍按节目原有频率换帧；只有实际画了新屏幕帧才要求场景重绘，屏幕单独变化不重算全屋方向光阴影。静止且无屏幕变化时不提交 WebGL 帧；暂停稳定后亦不重复提交。没有减面、缩图或降低像素比/阴影分辨率。截图会重新更新对应视角的阴影，恢复旁观视角时再次失效缓存。

开发验证可在 URL 加 `?renderStats=1`，读取 Canvas 的 `data-render-stats`：累计场景帧数、请求阴影更新帧数、身体更新帧数和计时。它不是显卡利用率，不等于 3070 Ti 的性能实测；默认不暴露这组 DOM 调试计数；本地按窗口汇总的日志见 [Runner 与性能日志](RUNNER.md)。页面隐藏时仍沿用停止渲染/轮询的行为。

屏幕离开相机视锥或被父对象隐藏时，继续走节目时钟但不生成新纹理、不唤起全屋重绘；重新入镜立即补当前画面。这里只判断视锥/显式隐藏，不把包围盒遮挡当成真实可见性。角色视角截图也会先补齐该视角内的屏幕。

`renderStats` 还记录累计 draw calls、三角形和 CPU 绘制提交时间（不是 GPU 耗时）。开发对照用 `?renderStats=continuous` 恢复旧的持续身体/场景/阴影更新；不要日常开启。2026-11-06 本机同一 984×1538 家庭场景连续采样：闲置且电视/双屏播放时，按需版约 10.3 场景帧/秒、1.41 万 draw calls/秒，对照约 25.4 帧/秒、6.64 万 calls/秒；CPU 提交时间约 118 对 176 ms/秒。节目随机轮播、机器负载有波动，这不是 GPU 百分比或跨设备性能承诺。

近景跟随在人物停止后留 3 秒收敛时间，再停止重复插值；OrbitControls 小于 1e-6 的矩阵浮点抖动不触发重画。人物重新移动或切换镜头时恢复跟随，拖动/缩放仍由 OrbitControls 自身事件即时更新。
