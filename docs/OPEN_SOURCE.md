# 公开发布前检查

本页是发布待办，不是“已核准所有素材、已上公网”的声明。2026-11-15 本轮整理时 GitHub 仓库为私有，实际发布状态以 GitHub 为准。文档整理不会改变仓库可见性、提交代码、推送或重写历史。

## 1. 隐私与历史检查

```sh
node tools/check-public.mjs --history --output artifacts/public-review/report.json
```

检查已跟踪文件及未忽略的新文件，包括 GLB 的 JSON 元数据、压缩测试样本、部分 JPEG EXIF 身份/GPS 标签；`--history` 另读取本机所有可达 Git 引用中的历史 blob。遇到高置信度凭据或禁止分发的本地文件，退出非零；输出只含规则、位置和对象 ID，不回显命中值。

它**不触网、不读取系统密钥链**；除显式指定的本地报告外，不修改源码、素材或 Git 历史。符号链接只列为人工检查项，不读取链接指向的外部文件。它不是 gitleaks 的完整替代品，更不能保证穷尽所有秘密、图片像素中的个人信息或法律风险。未覆盖 GitHub 的 Issue/PR、只在远端的引用、Release 附件、LFS 存储、不可达对象及已被第三方下载的副本；正式公开时还需人工检查这些范围。

- `house3d/data/`：用户存档和动态内容；`artifacts/`：测试数据、截图、日志、打包文件和本机审查报告。保持本地，不入库。
- `.env*`、证书/私钥、Cookie、账号登录/付款材料、HAR、数据库、日志和原始模型下载不得随源码发布。样例变量文件只能含确实无秘密的占位内容。
- `.gitignore` 只影响后续未跟踪文件，不能从历史撤回已提交的内容。`git check-ignore` 与历史扫描都要做。
- 源码里的服务任务 ID、贡献者署名、公开邮箱、固定示例区坐标不是一律需要抹掉的秘密；保留必要来源。真正含认证信息、个人地址或签名的链接另行处理。
- 发现真实凭据先撤销/轮换，再决定如何处理历史。不要直接 force-push 或宣布“删文件就安全了”。

## 2. 当前素材的公开阻塞

**本轮未取得完整素材包的逐项分发确认，不能直接标成“全仓 MIT / 可任意商用”。**

1. 默认大肥鱼角色属于社区设计衍生链，现存记录带 CC BY-NC-SA 4.0、上游署名和额外参考权利边界。需要确认当前 3D 成品的衍生分发条件，不只是保留模型文件。
2. Tripo 家具和人物需要补生成时的套餐、合法账号使用依据、当时适用条款与输入图来源。付费积分数量和当前账号套餐不是每件旧模型的授权证明。
3. 原生几何、绘本/家庭插图、贴图与文档截图分开核对；内嵌图片也要检查，不能只审核 `.jpg` 或文件名。
4. 保存权利证明时使用可公开的来源和条款摘要；账单、邮箱、登录资料等完整记录只放本地。不能确认的素材需取得授权、替换，或从明确的公开发行范围中排除，且不能让页面悄悄缺模。

完整范围和参考链接见 [LICENSING](LICENSING.md)；制作记录见 [ASSETS](ASSETS.md)。若先发布代码、不附未核准的美术，需要单独设计明确的素材安装/替换方式与可运行的默认场景，不能把损坏的包称为零安装成品。本轮没有擅自执行这项拆分。

## 3. 说明与功能边界

- 默认需要 Node.js 22.12+ **及现有 Chrome/Chromium**。`--no-runner` 可用可见页面执行，不代表没有执行页面也能动。
- `runtime/` 是随发行物提供的预构建成品，包含共享后端 chunk，不是启动时下载依赖或自动重新构建。
- 有限生活安排执行完会停止；持续自主选事、模型唤醒和外部 Agent 记忆尚未接入。不要把预录动作链写成“全天自动生活”。
- 已有预设多房间、坐卧、画画与家务，不等于任意角色/任意家具都支持。所有能力以查询接口及真实回报为准。
- 默认只监听本机，不提供公网认证。模型生成/图片服务不在运行调用链，天气服务是可关闭的例外；商业部署另核对其服务条款。
- 历史迁移/性能文档只说明当时的测试条件，不是今天所有 WSL、手机、GPU 的性能保证。文件体积不等于显存占用。
- `package.json` 的 `private: true` 是防误发 npm 的标志，**不影响 GitHub 仓库能否开源**，不应为改 GitHub 可见性而顺手移除。

- [ ] README、SKILL、运行 ZIP 文档和工具 schema 相符；公开截图展示的功能确实存在。
