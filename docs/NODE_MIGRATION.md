# Node 零安装运行迁移

## 范围

保留当前 API、工具、SQLite 表结构、版本/幂等、布置预演、状态机、角色反馈和画面，将 Python/Flask 生产代码替换为 TypeScript + Node 内置模块。完整本机工程、旧服务和资产均不改动。

入口 `node start.mjs`；CLI `node agent.mjs`。Node 22.12 自动补内置 SQLite 开关，不调用 npm/Python/构建器。前端和后端构建产物位于 runtime，发布包携带它们。

## 验证方法

1. 从提交 473f525 的原 Python 实现和 103 项测试提取 300 组 HTTP 契约：请求、目录覆盖、固定时钟、返回状态/JSON、数据库前后表。
2. Node 对这些样本逐项重放，对比 JSON（浮点容差 1e-9）及落盘内容。Python 序列化的旧幂等记录也参与重放，不只测新生成的 Node 数据。
3. 保留 62 项原浏览器/模型/动作测试；增加旧 SQLite 模式重开、错误参数、事件裁剪和产物运行测试。
4. 实际解压 ZIP 到临时目录，仅以绝对路径 Node 启动、PATH/NODE_PATH 置空；不携带 node_modules，不执行 npm/Python 或构建。测试网页、全部家具、Host/CORS、错误 JSON、5 MiB 上限、模板预演/应用、截图队列和 CLI。
5. 用 runtime-assets.json 校验 56 个原运行资产，确保人物、贴图和动画字节不变。

最终测试数、包大小与本机浏览器结果见本次交付记录；原始样本来源见 tests/python-contracts-info.json。本轮没有自动提交、推送或创建 GitHub Release；远端初始版仍是 Python。

## 仍需面对的边界

Node 内置 SQLite 在部分版本仍有官方实验提示；没有将它谎称为任意 Node 版本都可运行。迁移验收时默认只监听本机，身体动作和截图依赖可见浏览器；当前默认执行方式见 [Runner 说明](RUNNER.md)。迁移不是无头渲染、WSL/手机性能或通用角色系统的验收。
