# Agent Home development instructions

- Read README.md, docs/AGENT_GUIDE.md and docs/ARCHITECTURE.md first.
- This is the lightweight runnable repository. The full local modeling archive remains in the neighboring dafeiyu-home project; do not delete, migrate or overwrite that archive.
- The user authorized initial private GitHub publication. Subsequent commits/pushes require a new explicit request.
- Keep the accepted character appearance, animations and single-Canvas UI. Runtime assets were copied byte-for-byte; verify runtime-assets.json before changing them.
- Preserve asset provenance and all license files. Code licensing is not permission to commercially redistribute character art.
- Keep the tracked working tree below 100,000,000 bytes. Exclude historical candidates, Blender projects, raw downloads and runtime state rather than silently reducing visual quality.
- Do not change DSH, QQ, credentials, model settings or existing scheduled tasks.
- Do not claim an accepted command is a completed movement. Inspect the matching job and fresh body feedback.
- Do not add public remote access, headless execution, arbitrary shell tools or paid services without a separate explicit request.
